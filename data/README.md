# Data and fixtures

No corpus, importer or measured benchmark is committed here. Existing synthetic wire fixtures are in [contracts](../contracts/phase1/examples/manifest.json); live generation cases are under `backend/tests/phase1/generation/`.

Hassan owns imports/provenance, Naveed answer labels/rubrics and Zaid frontend mocks. Start with a small synthetic PDF/DOCX corpus.

Future `samples/`, `evaluation/` and `fixtures/` directories are proposals. Record revision, license, selection rules, stable source IDs, question coverage and development/held-out splits. Keep large downloads outside Git; no dedicated full-corpus ignore rule exists.

See [evaluation strategy](../docs/EVALUATION_STRATEGY.md). Source-system records need deliberate import/adaptation and do not expand Phase 1 uploads beyond PDF/DOCX.
