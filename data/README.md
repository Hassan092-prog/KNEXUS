# KNEXUS Data & Fixtures

This directory holds dataset samples, evaluation fixtures, and synthetic test suites.

## Contents & Structure
- `samples/` — Curated subsets of enterprise documents (Slack, Linear, Gmail, Drive).
- `evaluation/` — 500-question benchmark set (Basic, Semantic, Intra-document, etc.).
- `fixtures/` — Security test suites (RBAC roles, multi-tenant isolation, approval scenarios).

> **Note:** Raw large data files and full benchmarks should remain gitignored. Place only normalized fixtures and synthetic test sets here.
