# API Specification

**Version:** 1.0 | **Base URL:** `http://localhost:8010/api/v1` | **Last Updated:** October 2026

## 1. Authentication

All endpoints (except `/auth/login` and `/health`) require:

```
Authorization: Bearer <access_token>
```

### POST `/auth/login`
**Description:** Authenticate and receive JWT tokens.

**Request:**
```json
{
  "email": "user@company.com",
  "password": "securepassword"
}
```

**Response `200 OK`:**
```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer",
  "expires_in": 7200,
  "user": {
    "id": "uuid",
    "email": "user@company.com",
    "role": "employee",
    "org_id": "uuid"
  }
}
```

**Errors:**
- `401 Unauthorized` — Invalid credentials

---

### POST `/auth/refresh`
**Description:** Exchange a refresh token for a new access token.

**Request:**
```json
{ "refresh_token": "eyJ..." }
```

**Response `200 OK`:**
```json
{ "access_token": "eyJ...", "expires_in": 7200 }
```

---

### POST `/auth/logout`
**Description:** Invalidate current session tokens.

**Response `204 No Content`**

## 3. Documents

### POST `/documents/upload`
**Auth:** Required | **Roles:** `OrgAdmin`, `SuperAdmin`

**Request:** `multipart/form-data`
| Field | Type | Required | Description |
|---|---|---|---|
| `file` | `file` | Yes | PDF or DOCX file |
| `title` | `string` | No | Override detected title |
| `allowed_roles` | `string[]` | Yes | e.g. `["employee", "manager"]` |
| `description` | `string` | No | Short description |

**Response `202 Accepted`:**
```json
{
  "document_id": "uuid",
  "task_id": "uuid",
  "status": "queued",
  "message": "Document received. Processing in background."
}
```

---

### GET `/documents`
**Auth:** Required | **Roles:** All

**Query Params:** `limit=20&offset=0`

**Response `200 OK`:**
```json
{
  "data": [
    {
      "id": "uuid",
      "title": "Employee Expense Policy 2026",
      "source_type": "pdf",
      "status": "complete",
      "allowed_roles": ["employee", "manager"],
      "chunk_count": 42,
      "created_at": "2026-10-18T12:00:00Z"
    }
  ],
  "meta": { "total": 1, "limit": 20, "offset": 0 }
}
```

> **Note:** Results are automatically filtered to only documents the requesting user's role is allowed to see.

---

### GET `/documents/{document_id}`
**Auth:** Required | **Roles:** All (filtered by permission)

**Response `200 OK`:**
```json
{
  "id": "uuid",
  "title": "Employee Expense Policy 2026",
  "source_type": "pdf",
  "status": "complete",
  "allowed_roles": ["employee", "manager"],
  "chunk_count": 42,
  "metadata": { "author": "HR Dept", "pages": 12 },
  "created_at": "2026-10-18T12:00:00Z"
}
```

**Errors:**
- `403 Forbidden` — User role not in `allowed_roles`
- `404 Not Found`

---

### GET `/documents/{document_id}/status`
**Auth:** Required | **Roles:** `OrgAdmin`, `SuperAdmin`

**Response `200 OK`:**
```json
{
  "document_id": "uuid",
  "status": "processing",
  "chunks_processed": 18,
  "total_chunks": 42,
  "progress_percent": 43
}
```

---

### DELETE `/documents/{document_id}`
**Auth:** Required | **Roles:** `OrgAdmin`, `SuperAdmin`

**Response `204 No Content`**

## 4. Knowledge Query (RAG)

### POST `/query`
**Auth:** Required | **Roles:** All

**Request:**
```json
{
  "question": "What is the daily meal allowance for business travel?",
  "top_k": 5,
  "stream": false
}
```

**Response `200 OK` (non-streaming):**
```json
{
  "answer": "According to the Expense Policy 2026, the daily meal allowance for domestic business travel is ₹1,500 per day [1]. For international travel, this increases to $50 per day [2].",
  "citations": [
    {
      "id": 1,
      "document_id": "uuid",
      "document_title": "Employee Expense Policy 2026",
      "chunk_index": 7,
      "excerpt": "Daily meal allowance for domestic travel: ₹1,500 per day...",
      "similarity_score": 0.87
    },
    {
      "id": 2,
      "document_id": "uuid",
      "document_title": "International Travel Policy",
      "chunk_index": 3,
      "excerpt": "International per diem: $50 USD per day...",
      "similarity_score": 0.79
    }
  ],
  "abstained": false,
  "session_id": "uuid",
  "meta": {
    "retrieval_time_ms": 45,
    "generation_time_ms": 2340,
    "model": "llama3.2"
  }
}
```

**Response `200 OK` (abstention):**
```json
{
  "answer": null,
  "citations": [],
  "abstained": true,
  "abstention_reason": "No relevant evidence found in your accessible documents. Please refine your query or contact your admin.",
  "session_id": "uuid"
}
```

---

### GET `/query/stream/{session_id}`
**Auth:** Required | **Content-Type:** `text/event-stream`

**Description:** SSE stream endpoint. After calling `POST /query` with `"stream": true`, the response includes a `session_id`. Connect to this endpoint to receive the token stream.

**SSE Event Format:**
```
event: token
data: {"token": "According", "done": false}

event: token
data: {"token": " to", "done": false}

...

event: done
data: {"citations": [...], "session_id": "uuid"}
```

## 5. Actions (Human-in-the-Loop)

### POST `/actions/propose`
**Auth:** Required | **Roles:** `Employee`, `Manager`, `OrgAdmin`

**Request:**
```json
{
  "tool_name": "create_task",
  "payload": {
    "title": "Update expense report template",
    "assignee_id": "uuid",
    "due_date": "2026-11-01"
  }
}
```

**Response `202 Accepted`:**
```json
{
  "proposal_id": "uuid",
  "status": "pending_approval",
  "payload_hash": "sha256:a3f7c2d...",
  "expires_at": "2026-10-18T19:00:00Z",
  "message": "Action submitted for manager approval."
}
```

**Errors:**
- `400 Bad Request` — Tool not in registry or invalid payload schema
- `403 Forbidden` — User lacks permission for this tool

---

### GET `/actions/proposals`
**Auth:** Required | **Roles:** `Manager`, `OrgAdmin`, `SuperAdmin`

**Query Params:** `status=pending&limit=20&offset=0`

**Response `200 OK`:**
```json
{
  "data": [
    {
      "proposal_id": "uuid",
      "tool_name": "create_task",
      "proposed_by": { "id": "uuid", "name": "John Doe", "role": "employee" },
      "payload": { "title": "Update expense template", ... },
      "payload_hash": "sha256:a3f7...",
      "status": "pending_approval",
      "created_at": "2026-10-18T18:00:00Z",
      "expires_at": "2026-10-18T19:00:00Z"
    }
  ],
  "meta": { "total": 1, "limit": 20, "offset": 0 }
}
```

---

### POST `/actions/{proposal_id}/approve`
**Auth:** Required | **Roles:** `Manager`, `OrgAdmin`

**Response `200 OK`:**
```json
{
  "proposal_id": "uuid",
  "status": "executed",
  "result": { "task_id": "uuid", "status": "created" },
  "executed_at": "2026-10-18T18:05:00Z"
}
```

**Errors:**
- `409 Conflict` — Payload hash mismatch (tamper detected)
- `410 Gone` — Proposal expired

---

### POST `/actions/{proposal_id}/reject`
**Auth:** Required | **Roles:** `Manager`, `OrgAdmin`

**Request:**
```json
{ "reason": "Invalid assignee for this task." }
```

**Response `200 OK`:**
```json
{ "proposal_id": "uuid", "status": "rejected" }
```

## 8. Common Error Responses

| Status | Code | Description |
|---|---|---|
| `400` | `VALIDATION_ERROR` | Request body fails schema validation |
| `401` | `UNAUTHORIZED` | Missing or invalid JWT |
| `403` | `FORBIDDEN` | Valid JWT but insufficient role |
| `404` | `NOT_FOUND` | Resource does not exist or is in another org |
| `409` | `CONFLICT` | Hash mismatch or resource state conflict |
| `410` | `GONE` | Approval expired |
| `422` | `UNPROCESSABLE` | Pydantic validation failure |
| `500` | `INTERNAL_ERROR` | Unexpected server error |

**Error Response Shape:**
```json
{
  "detail": "Insufficient permissions to access this resource.",
  "code": "FORBIDDEN",
  "request_id": "uuid"
}
```
