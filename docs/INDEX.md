## 🗺️ Reading Order (for new team members)

1. Start with [PRD.md](PRD.md) — understand **what** we are building
2. Read [ARCHITECTURE.md](ARCHITECTURE.md) — understand **how** it fits together
3. Study [DATABASE_SCHEMA.md](DATABASE_SCHEMA.md) — understand the data model
4. Read [SECURITY_MODEL.md](SECURITY_MODEL.md) — understand the security boundaries
5. Reference [API_SPEC.md](API_SPEC.md) — while building frontend/backend
6. Follow [TRD.md](TRD.md) — coding standards and environment constraints
7. Use [EVALUATION_STRATEGY.md](EVALUATION_STRATEGY.md) — when building tests
8. Follow [../CONTRIBUTING.md](../CONTRIBUTING.md) — for day-to-day git workflow
